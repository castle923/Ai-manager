# M4 한국어 TTS 실행 보고서

기록일: 2026-10-16 · 버전: v0.4.0 · 판정: 승인된 M4 첫 한국어 TTS 실행 범위 완료. 최종 소스의 실제 생성·파일 검증·브라우저 재생·저장·실행 취소와 독립 검토를 통과했다. 게시 내용은 고정 커밋과 대조 검증한다.

## 승인과 사용 자산

사용자는 첫 모델의 실제 로딩·한국어 TTS 추론·WAV 생성, 실행 UI·오류·취소, 검증·문서·비식별 저장소 반영을 명시 승인했다. M5 두 모델 비교와 이후 단계, 작업공간 커스텀, 원격 GPU와 공개 서비스 운영은 범위에 포함하지 않는다.

기존 허용 자산은 동일 프로젝트에서 M3에 준비한 `Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice` 모델 13개 파일이다. 공식 revision은 `85e237c12c027371202489a0ec509ded67b5e4b5`, 전량 크기는 2,498,388,392 bytes다. M4에서 새로 13개 실제 바이트 해시가 고정 manifest와 일치함을 확인했다. 이전 M3의 성공 기록을 이번 실행의 검증으로 대체하지 않는다. 매 추론에서도 전량 해시와 허용 파일 집합을 다시 확인한다.

공개 의존성은 별도 추론 환경의 lock으로 고정한다. 이번 환경은 Windows, Python 3.10.11, qwen-tts 0.1.1, PyTorch 2.9.1+cu128, transformers 4.57.3과 RTX 3070 8 GiB다. 공식 [모델 카드](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice/tree/85e237c12c027371202489a0ec509ded67b5e4b5)와 [공식 실행 라이브러리](https://github.com/QwenLM/Qwen3-TTS)를 출처로 사용한다. 과거 다른 프로젝트 코드·이미지·WAV·프롬프트·측정값을 입력으로 가져오지 않는다.

## 이번 구현

- 한국어 실행 작업실: 새 텍스트, 실행·대기·취소 중·완료·오류 상태, 실행 기록, WAV 재생·저장.
- 별도 작업 프로세스: 오프라인 로컬 모델 로딩, `trust_remote_code=False`, CUDA bfloat16 / SDPA, 매 실행 콜드 로딩.
- 제한: Korean / Sohee / batch 1, instruct 제외, 최대 300자·600초·1,024개 신규 토큰. 실행 1개와 대기 최대 3개. 새 seed를 생성하고 기록한다.
- 출력 검증: EOS 종료 필수, PCM16 mono 24 kHz, 최대 120초·6 MB, RMS가 0보다 큼, clipping 비율 최대 1%. 파일·형식·수치 검증은 발음이나 내용 정확도 평가와 구분한다.
- 실행 출처: 새 run_id와 고유 출력 디렉터리, 입력 해시, 모델 해시, 소스·런타임 lock 해시, 실제 시각과 상태, 검증한 WAV 해시. 비공개 기록은 저장소 밖 앱 전용 경로에 보관한다.
- API: `/api/tts/status`, `/api/tts/runs`, 실행 상세·취소·오디오 경로. 대기·실행 취소와 시간 초과가 성공으로 기록되지 않으며 작업 프로세스 트리를 정리한다.

오디오 Range 요청은 현재 전체 파일 200 응답으로 처리한다. 부분 응답 206이나 정밀 seek 지원을 검증했다고 주장하지 않는다. 실행 입력·출력·로그·스크린샷·개인 절대경로는 공개하지 않는다.

## 실패 기록과 수정

개발 중 첫 실제 입력 실행은 약 240.109초 뒤 EOS 확인 로직 오류로 실패했고 WAV를 생성하지 않았다. 당시 검사 로직이 생성 결과의 hidden states를 과도하게 요구했다. 최종 코드는 sequences의 마지막 EOS를 검사하도록 수정했으며 EOS가 없는 결과와 올바른 EOS 결과의 독립 테스트가 통과했다. 이 중간 실패는 보존했고 성공 실적으로 포함하지 않는다. 해당 실패만으로 모델의 한국어 생성 능력이나 입력 길이 한계를 판정하지 않는다.

최종 소스의 성공 실행 ID는 `f8f6d0c17de6495983b7d2f4ea269308`이다. 출력 SHA-256은 `945b1b06ab1758404fe29b233b55fa35a261f178ad7835ebc4644021fe7f83e2`다. 독립 WAV 검사에서 76,800 frames·peak 0.546875·RMS 0.089976·clipped 0을 확인했고 API 200의 전체 바이트가 로컬 파일·state 해시와 일치했다. 실제 모델 로딩 4.88초·추론 28.14초·전체 54.77초, PyTorch peak GPU allocated memory 2.11 GiB로 기록됐다. 이 값은 전체 장치 VRAM 사용량이나 다른 프로세스의 메모리를 포함하지 않는다. 표본 1개의 콜드 실행이며 다른 길이·문장·환경의 성능 또는 메모리 상한을 보장하지 않는다. 실제 입력 전문은 비공개 실행 기록에만 보관한다. 실행의 소스 해시는 최종 코드와 일치함을 확인했다.

실제 취소 실행 ID는 `5b5498b82b844340af17b963d62fe127`이다. 새 실행이 running 상태인 동안 UI에서 취소했고 cancelling을 거쳐 약 40.59초에 cancelled로 종료했다. WAV·성공 출력이 없다. 대기 작업 취소·큐 포화·장시간 순차 실행은 자동 계약 테스트와 실제 E2E를 구분한다. 이전 개발 실행 결과를 최종 소스의 성공 근거로 전용하지 않는다.

## 보존·재사용·게시 범위

확인 범위는 이번 구현의 입력 계약, 지정 모델 준비 경로, 실행별 출력·출처 경로, 테스트·wheel에 포함한 파일이다. 모델·패키지 캐시는 허용 자산으로만 사용하고 결과 캐시는 새 실행과 분리한다. 다른 프로젝트 저장 위치 전체를 감사한 것은 아니므로 전 디스크의 재사용 부재를 단정하지 않는다.

이번 새 산출물은 TTS worker·작업 조정 코드, UI, 독립 테스트, 문서와 새 비공개 실행 기록이다. 기존 Drive 파일·다른 프로젝트·중간 실패 기록은 보존했다. 공개 반영은 명시한 소스·테스트·lock·문서 whitelist만 사용하며 개인 계정·Drive ID·인벤토리·입력/WAV·스크린샷·로그·자격 증명·실제 절대경로를 제외한다. 상위 작업공간 AGENTS.md는 승인 범위만 로컬 갱신하고 게시하지 않는다.

## 완료 판정과 남은 제한

최종 소스에서 새 WAV 생성·파일 무결성·브라우저 재생·저장·실제 작업 취소를 확인했다. 독립 WAV·입력/소스/응답 바이트 연결, 작업 프로세스 종료·active 해제, 대표 폭의 최종 상태·키보드 접근 검토를 통과해 승인된 M4 범위를 완료로 판정한다. 실제 대기 작업 취소는 미검증으로 남기며 이번 범위의 추가 완료 조건으로 확대하지 않는다. GPU 전체 할당이나 장치의 모든 자원 해제를 측정한 것은 아니다. 실제 GPU OOM, 장시간 순차 실행, 300자 전 범위, 사람의 청취·내용 정확도·품질 비교는 미검증이다. 자동 오류 주입과 실제 정상·취소 E2E를 별도로 보고한다. M5 비교·추가 모델·개인용 출시의 승인 여부는 [승인 기록](APPROVALS.md)을 따른다.
