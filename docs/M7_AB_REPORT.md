# Windows 독립 앱 — 새 1.7B 실행과 A/B 검증

기준일: 2026-10-17 · 0.7.1 후보 desktop-7.1-2 · 새 A/B 실행·재생·native 저장 검증 완료 / 공개 배포는 v0.7.0 유지

사용자가 Windows 독립 앱에서 지정 1.7B를 실행하고 같은 새 한국어 입력으로 0.6B/1.7B를 비교·재생·저장하며 결과와 소스를 저장소에 반영할 것을 승인했다. 이번 결과는 새 0.7.1 후보 설치본과 새 런타임·모델 준비·입력·출력의 증거다. 기존 [v0.7.0 보고서](M7_REPORT.md)의 0.6B 단일 실행 이력이나 과거 A/B 출력으로 대신하지 않았다. 기존 v0.7.0 Release·태그·ZIP은 보존하며 0.7.1 Release나 태그를 새로 게시한 상태가 아니다.

## 수정과 검증 경계

앞선 native 폴더 선택을 통한 B 준비 2회는 `size_mismatch`·검증 0/12로 실패했다. 지정 원본 12개와 config 해시는 정상이었으나 당시 실제 선택 경로가 기록되지 않아 원인은 미확정이다. 사용자 선택 실수나 원본 손상으로 단정하지 않는다.

0.7.1은 파일 검사 전에 선택 모델·실제 원본 폴더·첫 확인 파일의 기대/실제 크기를 비공개 준비 기록에 보존하고 앱 화면에 표시한다. 기존 native 찾아보기를 유지하면서 정상 제품 UI의 모델 선택·전체 절대경로 입력·**이 경로로 모델 준비**를 추가했다. 잘못된 경로 요청 뒤 이전 ready 상태가 현재 선택 결과처럼 남는 표시도 수정했다. 해시·크기 검사를 건너뛰지 않는다.

새 설치본의 163개 테스트(23.091초)와 독립 경계 17개, 패키지/설치본 검증을 확인했다. 경계 검증은 상대/누락/파일/빈값/개행/과대길이/순회/reparse/형식 오류 경로 거부, native 반환 형식·선택 모델/경로 전달, 외부 origin 거부와 후속 실패 상태 지속을 포함한다. 현재 source manifest 27개와 실제 설치 코드·번들 입력을 대조했고 실행 후 소스 변경은 없다. 새 런타임은 설치본에 포함된 Python 기반의 별도 환경으로 준비했다. 초기 시작에서 약 157초 지연 후 정상 창이 열렸으며 원인은 미확정이다. 별도 시작 최적화 제안은 비공개에 보존했고 이번 검증 소스·배포 후보에는 포함하지 않았다.

| 단계 | 이번 확인 결과 |
|---|---|
| B 새 준비 | 명시 경로를 기록한 새 준비에서 12개·4.52 GB의 원본/준비본/고정 manifest 크기·SHA-256 전량 일치 |

## 같은 입력과 측정 조건

새 한국어 입력은 70자이며 SHA-256은 `e66c520322523c4ec2fefb0ba2caf8a6256d76345e947670d964df248f80eb5e`다. 원문과 개인 실제 경로는 공개하지 않는다. 공통 seed는 `4178981254`, Korean·Sohee·batch 1·instruct 없음·max_new_tokens 1024다.

두 모델의 공통 sampling은 do_sample true·top_k 50·top_p 1.0·temperature 0.9·repetition_penalty 1.05·subtalker_dosample true·subtalker_top_k 50·subtalker_top_p 1.0·subtalker_temperature 0.9다. 각 모델은 콜드 1회이며 A 종료 뒤 B를 시작한 provenance를 확인했다. 입력·조건을 같게 했지만 출력 길이는 다를 수 있고, 아래 1회 수치를 일반 성능이나 품질 우열로 판정하지 않는다.

| 실제 결과 | A: 0.6B CustomVoice | B: 1.7B CustomVoice |
|---|---:|---:|
| 모델 로딩 | 5.829초 | 22.469초 |
| 추론 | 273.640초 | 403.921초 |
| PyTorch peak allocated | 2,557,792,256 bytes | 4,623,540,736 bytes |
| WAV | 606,764 bytes·12.64초 | 672,044 bytes·14.00초 |
| 형식 | PCM16 mono 24 kHz | PCM16 mono 24 kHz |
| EOS / clipped samples | true / 0 | true / 0 |
| SHA-256 | `890ef9fe53f971358f2121a1b41346ae43e30dbccb19adc06954ed5d52eae00d` | `246146ea58fdd97f4f2659eaf480785a1253c4bf724b69a7b898d014fd522fb3` |

PyTorch peak allocated는 전체 GPU VRAM 사용량이 아니다. 앱의 재생 종료·WAV 형식·EOS·클리핑 검사는 청취 품질이나 문장 내용의 정확성 판정이 아니다.

## 저장·공개 범위

A는 사용자 직접 저장 중 사전 안내와 다른 위치에 저장됐고, B는 그 현재 폴더에서 정상 저장 대화상자의 저장 버튼을 조작해 저장했다. 승인된 로컬 확인으로 두 새 파일을 찾아 각각 원본과 바이트·해시·형식·별도 파일 ID를 대조했다. 파일을 이동·삭제·재저장하지 않았고 새 WAV를 모델 입력이나 준비 manifest에 포함하지 않았다. 실제 개인 폴더·파일명·입력 원문·원시 로그·스크린샷은 공개하지 않는다.

이번 요청의 새 A/B·재생·저장 검증은 확인한 로컬 Windows·두 지정 모델·새 입력 1건 범위에서 완료했다. 0.7.1 후보는 로컬 검증 패키지이며 공개 다운로드는 [v0.7.0 Release](https://github.com/castle923/Ai-manager/releases/tag/v0.7.0)를 유지한다. 새 후보의 소스와 비식별 문서 반영은 공개 Release 게시와 구분한다. 모든 입력/PC·청취 품질 우열·장시간 stress·시작 지연 원인 해결을 주장하지 않는다.

검증한 로컬 후보 ZIP은 `AiManager-0.7.1-windows.zip`·58,406,893 bytes·SHA-256 `c4d94e2490deb121f9da3bc48b26c323dbc67f1cda25a5b1b5ca4fb832ef9e06`이다. 실행 후에도 설치 payload 4,285개와 전체 파일 집합 4,286개·source manifest 27개의 정합을 독립 확인했다. 새 [0.7.1 후보 시작 안내](M7_INSTALL.md)는 후보 빌드 당시 bytes로 동결하며 이 웹 보고서의 완료 기록과 구분한다.
