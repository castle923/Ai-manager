# Ai-manager 0.8.0 후보 — 시작과 모델 관리

기준일: 2026-10-17 · 새 빌드용 안내 초안 · 실제 설치·사용 검증 전

## 앱 실행과 준비

ZIP 전체를 새 폴더에 풀고 `AiManager.exe`를 실행합니다. `_internal` 등 동봉 파일을 함께 보존하며 실행 파일만 따로 옮기지 않습니다. 앱과 추론용 Python 기반을 포함하지만 시스템 WebView2 Runtime은 별도 전제입니다. 앱은 이를 자동 전역 설치하거나 보안 설정을 변경하지 않습니다. 명시적인 보안 차단은 우회하지 않습니다.

처음 화면에서 이번 프로젝트에 지정한 OAuth client/허용 목록 JSON을 고르고 새 작업실을 시작합니다. 계정 A/B의 Google 로그인·동의는 시스템 브라우저에서 사용자가 직접 진행합니다. 앱의 추론 환경 준비에는 인터넷과 수 GB의 공간이 필요합니다. 환경 점검 후 지정 모델 폴더를 준비하고 크기·해시 검사를 확인합니다. 모델·개인 인증 자료는 ZIP에 포함하지 않습니다.

기존 버전과 개인 작업실을 덮어쓰거나 자동 이전하지 않습니다. 별도 작업실 경로로 실행했다면 같은 실행 옵션을 유지합니다. 기본 작업실의 처음 화면이 열렸다는 이유로 기존 데이터가 삭제됐다고 판단하지 마세요.

## 모델 하나 등록하기

1. 기본 **모델 관리**에서 **모델 등록**을 누릅니다. 처음 registry는 비어 있으며 발견한 파일이나 과거 실행이 자동 등록되지 않습니다.
2. **모델 이름**, **용도**, **모델 설명**, **표시 버전**, **태그 (쉼표로 구분)**, **관리 메모**를 입력합니다. 표시 버전은 사용자가 붙이는 이름이며 가중치의 실제 revision과 다릅니다.
3. **파일 후보에서 등록**으로 수집된 후보의 관찰 위치/파일 구성을 참조하거나, 등록 화면에서 보관 위치를 지정합니다. 관찰 위치는 실제 실행에 사용할 모델의 바이트 검증을 대신하지 않습니다.
4. 실행할 경우 **실행 대상 구성**에서 지원하는 고정 TTS 구성을 선택합니다. 관리 정보는 다른 종류도 등록할 수 있지만 실제 실행은 지정된 두 Qwen TTS만 지원합니다.
5. 저장 후 등록 모델을 선택해 정보와 **현재 확인 수준**을 확인합니다. 등록만 하면 실행 검증 완료가 되지 않습니다.

지원하는 고정 TTS 구성을 선택하고 실제 로컬 원본 폴더를 지정하면 저장할 때 manifest에 명시된 구성 파일의 크기·SHA-256을 전량 확인합니다. 빈 폴더나 Drive 후보 관찰만으로는 구성 확인을 통과하지 않습니다. 상세의 확인 시각과 사유를 보고 필요한 원본/구성을 연결하세요. 미지원 모델의 설명·위치 등록은 가능하지만 실행·해시 검증까지 완료됐다는 뜻은 아닙니다.

## 상단 세 숫자와 새 실행

- **등록 모델**: 보관되지 않은 모델 수. 후보 파일 수가 아닙니다.
- **실행 검증 완료**: 현재 등록 구성에 명시 연결된 성공 근거가 있는 모델 수. 과거 음성 작업실의 성공을 자동으로 포함하지 않습니다.
- **구성 확인 필요**: 위치/구성이 미확인 또는 불완전한 모델 수. 상세 사유를 먼저 확인합니다.

준비한 지정 TTS의 모델 상세에서 **새 한국어 테스트 입력**을 작성하고 **이 모델 새로 실행**을 누릅니다. **모델 준비 확인**으로 필요한 준비 화면에 갈 수 있습니다. 성공 결과는 **이 모델의 실행 기록**에서 재생하고 **WAV 저장**으로 새 파일에 저장합니다. 저장 창의 상단은 폴더 위치, 하단 파일 이름은 새 WAV 이름입니다. 취소하면 저장하지 않으며 기존 파일에는 덮어쓰지 않습니다.

실행 직전 등록한 원본과 실제 준비된 모델의 내용 해시를 다시 대조합니다. 화면의 자동 갱신은 최근 검증 기록과 현재 파일 상태를 확인하는 것이며 매번 모델 전체를 다시 해시하지 않습니다. **실행 검증 완료**는 표시된 구성·최근 검증 시각·확인한 환경의 근거로 이해하세요.

정보 편집은 원본 모델 파일을 바꾸지 않습니다. 다른 화면에서 먼저 편집한 경우 충돌 안내에 따라 현재 값을 다시 불러옵니다. 보관 위치·실행 대상·실제 revision 변경은 기존 증거를 과거 구성으로 남기고 새 검증이 필요합니다. **모델 보관 (원본 보존)**은 원본/결과 삭제가 아닙니다. **보관 모델 포함**으로 찾아 **보관 해제 · 새 검증 필요**를 선택할 수 있습니다.

등록 정보는 새 registry DB, 파일 관찰은 기존 inventory DB에 분리됩니다. 기존 inventory 복구 안내가 registry·인증·모델·WAV 전체를 복원하는 것은 아닙니다. 오류를 해결하려고 개인 폴더를 삭제·이동하지 마세요.

이 안내는 현재 초안 UI의 사용 계약이며 실제 완료 증거가 아닙니다. 최종 확인 범위는 [M8 보고서](https://github.com/castle923/Ai-manager/blob/main/docs/M8_REPORT.md)를 따릅니다.
