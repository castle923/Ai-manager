# Ai-manager 0.7.0 독립 앱 시작 안내

기준일: 2026-10-17 · 현재 구현의 사용 절차 · 최종 설치·실행 검증은 진행 중

## 실행과 선택 설치

배포 ZIP을 새 폴더에 모두 풀고 `AiManager.exe`를 실행하세요. `_internal` 등 동봉 폴더와 파일은 실행 파일 옆에 그대로 둡니다. 실행 파일만 따로 옮기면 필요한 Python·DLL·화면 구성요소를 찾지 못할 수 있습니다. 명령어 입력이나 별도 Python 설치는 필요하지 않도록 구성한 앱입니다.

압축을 푼 위치에서 사용하거나, 처음 화면의 **사용자 폴더에 설치**를 선택할 수 있습니다. **설치할 상위 폴더 전체 경로 (선택)**에 기존 상위 폴더의 전체 경로를 입력하거나 비워두고 폴더 선택 창에서 고릅니다. 그 아래 새 `AiManager-0.7.0` 폴더를 만들고 앱 파일의 버전·해시를 확인해 복사합니다. 같은 이름의 대상이 이미 있으면 덮어쓰지 않으므로 다른 상위 폴더를 선택하세요. 설치 완료 안내가 나오면 현재 창을 닫고 새 폴더의 `AiManager.exe`를 실행하세요. 기존 앱·개인 작업실을 삭제하거나 자동 이전하는 기능은 아닙니다.

Microsoft Edge **WebView2 Runtime**은 별도 시스템 전제입니다. 앱 창을 시작하지 못하면 안내된 WebView2 설치 상태와 앱 파일 무결성을 확인하세요. 앱은 WebView2를 자동 전역 설치하지 않습니다. 서명되지 않은 앱에 경고나 명시적인 차단이 나오면 출처와 배포 해시를 확인하고 중단하세요. 보안 설정을 해제하거나 우회해서 실행하지 않습니다.

## 새 작업실 준비

1. **OAuth client 선택**과 **허용 목록 선택**에서 이번 프로젝트에 지정한 원본 JSON 두 개를 고릅니다. 또는 **OAuth client 원본 전체 경로**·**허용 목록 원본 전체 경로**에 각 파일의 전체 절대경로를 입력하고 해당 **경로 적용** 버튼을 누릅니다. 두 파일이 선택되면 **새 작업실 시작**을 누릅니다. 경로 입력에도 PowerShell·Python 명령은 필요하지 않습니다. 인증 정보·모델 가중치는 배포 ZIP에 들어 있지 않습니다.
2. 앱의 계정 연결 화면에서 계정 A/B를 각각 연결합니다. 시스템 Edge가 있으면 OAuth에 사용하며, 없으면 시스템 브라우저가 열릴 수 있습니다. Google 로그인과 권한 동의는 사용자가 직접 진행합니다. 연결·갱신 상태를 확인한 뒤 읽기 전용 목록을 새로 수집합니다. 이전 작업실의 토큰·목록·출력을 복사하지 않습니다.
3. **앱 추론 환경**의 **추론 환경 준비**를 누릅니다. Python 기반 런타임은 동봉되지만 첫 준비에는 Torch 등 공개 의존성을 내려받을 인터넷과 수 GB의 여유 공간이 필요합니다. 소요 시간·전송량은 환경에 따라 달라집니다. 준비 상태를 확인하고 실패하면 연결·공간·앱 무결성을 확인한 뒤 표시된 **다시 준비**를 사용합니다. 설치 완료는 모델 실행 성공을 뜻하지 않습니다.
4. **모델 준비** 화면의 **환경 점검**에서 현재 환경을 확인합니다. 이 점검은 의존성과 장치를 검사하며 모델 로딩 자체를 검증하지 않습니다.
5. **0.6B 폴더 선택**, **1.7B 폴더 선택**으로 지정된 Qwen3-TTS CustomVoice 모델의 가중치·config·tokenizer를 포함하는 원본 폴더를 각각 고릅니다. 지정 파일만 새 준비 기록으로 복사하고 해시를 확인합니다. **모델 파일 준비·무결성 확인 완료** 상태를 확인하세요. **모델 준비 취소**는 준비를 중단하며 원본을 보존합니다.

앱의 추론 환경 ID를 확인하세요. 설치 위치·동봉 Python·의존성 구성에 따라 별도 환경을 준비하며, 동일 위치·동일 구성의 정상 재시작은 같은 ID를 사용합니다. 앱을 다른 위치로 옮기거나 구성이 바뀌면 새 준비가 필요할 수 있습니다. 동봉 Python 기반 폴더를 삭제하거나 따로 이동하지 마세요. 이전 환경은 새 환경 준비를 이유로 자동 삭제하지 않습니다.

## 새 음성 실행과 저장

두 모델과 환경이 준비되면 비교 화면에 새 한국어 입력을 작성하고 A/B를 실행합니다. 완료·실패·취소 상태를 구분하고 성공한 음성만 앱에서 재생합니다. 환경 점검이나 파일 해시 통과만으로 음성 생성 성공을 대신하지 않습니다.

**A WAV 저장** 또는 **B WAV 저장**을 누르면 Windows 저장 창이 열립니다. 새 파일 이름과 기존의 정상 폴더를 선택하세요. 취소하면 저장하지 않습니다. 이미 존재하는 파일에는 덮어쓰지 않으므로 다른 새 이름을 선택합니다. 저장 결과의 상태·바이트·해시를 확인하고 실패하면 기존 파일을 보존한 채 표시된 원인을 확인하세요. 브라우저 다운로드 설정을 바꾸거나 다른 저장 방식으로 우회할 필요는 없습니다.

## 종료·재시작과 보존

앱 창을 닫으면 이 앱이 소유한 준비 작업·backend·worker의 종료 절차를 수행합니다. 다시 실행하면 같은 작업실의 기록을 확인합니다. 중단된 실행이 자동으로 성공하거나 음성 생성이 이어졌다고 판단하지 마세요. 재실행은 새 입력과 새 실행으로 구분합니다.

개인 작업실과 모델 원본을 앱 폴더의 불필요한 파일로 취급해 삭제하지 마세요. 기존 [복구 안내](https://github.com/castle923/Ai-manager/blob/main/docs/RECOVERY.md)는 v0.6.0 CLI의 정상 inventory snapshot을 새 대상에 복원하는 절차입니다. 이 독립 앱의 GUI 백업·자동 이전 기능을 뜻하지 않으며 인증·모델·WAV 복원이나 손상 DB 원본 수리도 아닙니다. 이번 배포의 실제 확인 범위는 [M7 보고서](https://github.com/castle923/Ai-manager/blob/main/docs/M7_REPORT.md)를 따릅니다.
