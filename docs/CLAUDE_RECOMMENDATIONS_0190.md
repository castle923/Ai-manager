# Ai Manager 0.19.0 — Claude 후보 분류·추천

파일 후보 탐색에서 작업 목적을 선택하거나 유형별 작업실을 열면 **Claude 후보 분류·추천**을 사용할 수 있습니다. 기본값은 꺼짐입니다. 기존 로컬 목록과 순서는 그대로 유지하고 Claude 결과는 별도 표에 표시합니다. 이번 기능은 폴더 metadata의 목적 관련성을 추정하는 보조 도구입니다. 모델 식별, 가중치 완전성, 성능 우열이나 실행 지원을 인증하지 않습니다.

## 선택 → 전송 미리보기 → 동의 → 결과

1. 켜기와 목록 새로고침은 로컬 조회만 합니다. 신규·변경 표시도 현재 수집된 목록을 로컬에서 비교하며 Drive 재수집이나 자동 API 전송을 하지 않습니다.
2. 선택한 작업에서 최대 20개 후보를 고릅니다. 신규 후보와 기존 후보를 함께 비교할 수 있습니다. 순위는 **선택한 후보 사이의 상대적 검토 순서**이며 미선택 후보는 순위 밖입니다.
3. 전송할 표시명을 검토·편집하거나 이름 전송을 해제합니다. 이름에도 개인 정보가 있을 수 있습니다. 절대경로·계정 주소·제어문자 등은 거절합니다. 외부 모델명은 비신뢰 데이터로 취급하며 명령으로 실행하지 않습니다.
4. API 키는 단일 workspace 전용 키를 직접 입력합니다. Windows DPAPI로 별도 보호하며 평문 저장으로 전환하지 않습니다. 입력 필드는 제출 즉시 비웁니다. 키 저장만으로 API를 호출하지 않습니다.
5. Messages와 무료 count 요청의 **정확한 JSON**, 공급자·모델·요율 확인일·외부 전송 항목·숫자 시나리오 견적·예산·보관 정책을 확인합니다. 미리보기 생성도 외부 전송을 하지 않습니다.
6. 명시 동의 후 무료 count 1회, 예산 검사를 통과하면 유료 Messages 1회만 보냅니다. 동의는 한 번만 사용하며 후보·이름·키·예산·출처가 바뀌면 새 미리보기가 필요합니다. 미리보기는 10분 후 만료합니다.

대상은 프로그램의 현재 수집 후보입니다. 등록 로컬 모델이나 외장 드라이브를 새로 재귀 탐색하지 않습니다. 전송 항목은 선택 작업, 요청 내부 별칭, 사용자가 승인한 표시명(선택), metadata 종류, 파일 수, 관측 bytes, 고정 프로필 이름 단서 수와 근거 별칭입니다. **분류 본문에는 계정 주소, Drive/file/scan ID, 실제 경로, 개별 파일명, 파일 본문, 로컬 사양, Google OAuth 토큰·다른 보관소 비밀·API 키를 포함하지 않습니다.** Anthropic API 키는 TLS 인증 헤더로 고정 Anthropic에만 전송하며 미리보기·로그·응답에는 포함하지 않습니다. 관측 0 bytes와 용량 미확인을 구분합니다. count 요청도 같은 정보를 외부로 전송하므로 승인 전에는 호출하지 않습니다.

## 결과의 의미와 제한

결과는 작업 유형 추정, 관련성(높음·중간·낮음·미확인), 상대 순위와 근거를 보여줍니다. 이유는 Claude 자유 문장을 그대로 표시하지 않고 검증한 유형·적합도 및 승인된 근거 값으로 로컬에서 구성합니다. 이름에 근거한 추정은 이름 단서라고 표시합니다. 같은 관련성 안의 순서는 실측 성능 순위가 아닙니다.

단순 파일 수·크기·종류만으로 특정 작업의 높은 적합성을 채택하지 않습니다. 분류나 높은 적합도에는 승인된 이름 또는 프로필 단서가 필요합니다. 구성요소(tokenizer 등)·adapter는 독립 실행 모델로 승격하지 않습니다. 서버가 엄격한 schema, 현재 후보 집합, 근거 소유권, 중복·추가 필드, 순위 관련성 순서와 로컬 규칙을 검증합니다. 거절·잘림·잘못된 결과는 채택하지 않습니다.

이 화면은 `execution_allowed=false`, 실제 생성 없음 상태를 유지합니다. 기존 다섯 작업 유형·여섯 실행 프로필, 등록 모델 선택과 실행 검사는 그대로 적용합니다. Claude 결과로 모델 자동 등록, 다운로드, 가중치 검사나 실행을 시작하지 않습니다. 실패하면 기존 로컬 목록과 설명을 계속 사용할 수 있습니다.

## 비용·취소·데이터 보호

모델은 `claude-haiku-5-5`, Messages 서비스는 `standard_only`로 고정합니다. 확인한 기본 요율은 입력 100k 이하 $0.10/백만 토큰, 출력 $0.50/백만 토큰이며 초과 구간은 입력 $0.50·출력 $2.50입니다. 최대 출력은 2,048토큰입니다. 미리보기는 요청 UTF-8 bytes+4,096을 입력 토큰으로 가정한 **시나리오 USD 견적**을 보여줍니다. bytes는 토큰 수를 보장하지 않으며 schema/system overhead, 실제 usage, 계정 지역·세금·계약 조건은 별도입니다. 앱 예산은 공급자 청구 hard cap이 아닙니다.

무료 count만 전송한 뒤 실패·취소·출처 변경이면 Messages를 보내지 않고 관측 유료 비용 0으로 기록합니다. Messages 전송이 시작된 뒤 timeout 또는 usage 불명이면 청구 불명 예약을 유지하고 다음 유료 호출을 차단합니다. 잘못된 답이나 결과 보호 저장 실패에도 이미 관측한 usage를 보존합니다. 자동 재시도·redirect·백그라운드 전송은 없습니다. 취소는 이미 전송된 정보나 발생 비용을 되돌리지 못합니다.

API 키와 검증 완료 결과/context는 서로 다른 DPAPI 영역에 저장합니다. SQLite에는 별칭·로컬 연결 fingerprint·상태·usage 등 최소 기록만 저장하고 승인 표시명·근거 값·이유는 평문으로 저장하지 않습니다. 원시 요청·헤더·API 키는 로그나 결과에 저장하지 않습니다. 동일 출처·모델·prompt/schema 정책이면 재시작 후 보호된 결과를 다시 표시하며, 변경·복호화 실패·연결 불일치 때는 만료 또는 읽기 불가로 표시하고 자동 재전송하지 않습니다.

표준 상용 API 데이터는 일반적으로 30일 이내 삭제하나 법·정책·계약 예외가 있습니다. 사용자의 계정에 ZDR이 적용되는지는 확인하지 않았습니다. 일반 schema는 별도 cache될 수 있으므로 무보관이라고 설명하지 않습니다.

## 이번 검증 범위

새 격리 자료와 fake key/transport로 동의 전 외부 요청 0, 일회 동의, count/Messages 공통 본문, stale·취소·예산·청구 불명, 엄격한 결과 검증, DPAPI 결과 보존과 동일 출처 재시작을 검사했습니다. 별도 합성 HTTP 검증에서 Origin/CSRF 거절과 count 대기 중 조회·취소를 확인했습니다. 합성 Edge UI에서는 파일 후보 탐색과 작업실 연결, 최대 20개 선택, 미리보기 무효화, 키 입력 비우기, 중복 실행 방지, 순위·근거·좁은 화면을 확인했습니다. fake 응답은 렌더링·방어 검증용이며 분류 정확도 근거가 아닙니다.

최종 제품·문서를 동결한 전체회귀는 475개 중 468개 통과·7개 skip, 실패 0(266.478초)이며 실행 전후 225개 파일 상태·바이트가 동일했습니다. 별도 신규 target 19개도 통과했습니다. 앞선 중간 회귀는 실행 중 소스 변경을 감지한 `plan_code_or_catalog_stale` 실패 1개로 보존하고 최종 PASS 근거로 사용하지 않습니다. 기존 guard를 완화하지 않고 동결 후 해당 단독 회귀와 전체회귀를 새로 수행했습니다. UI 합성 화면은 최종 이유 설명 문자열 추가 전 렌더링·레이아웃 검증이며, 최종 설명은 target에서 유형·작업 일치 문장으로 확인했습니다.

**실제 API 키 조회·외부 API 호출·과금·실제 Claude 분류 정확도·새 패키지/native 동작은 아직 검증하지 않았습니다.** 실제 검증 전 별도 정확한 payload와 숫자 비용을 고지하고 사용자 승인을 받습니다. 이 단계는 기존 사용자 home·인증·DB·모델을 변경하지 않습니다.
