# 파일 후보 추천 0.16.0 검증 보고서

현재 상태: 구현·합성/API 회귀 검증 중인 로컬 수정 후보. 고정 소스 게시 후 새 Windows 패키지·격리 설치·실제 native UI 검증을 진행할 예정이다. 이 문서는 새 Release 또는 현재 사용 중인 앱의 교체 완료를 뜻하지 않는다.

## 변경과 원인 구분

파일 후보 탐색에 작업 목적 5종, 추천 우선 정렬, 그룹 검토번호, 선택 이유·기준·미확인 사항을 추가했다. 추천은 현재 작업실의 수집된 Drive 메타데이터를 읽는 검토 순서다. 실측 성능 수치나 모델 크기에 따른 품질 우열을 만들지 않는다. 필터 후 전역 정렬·번호 계산과 페이지 분할을 적용하고, 목적 전환·늦은 응답·오류 상태의 이전 추천 표시를 차단한다.

기존 dashboard API에 TTS만 수집·조회하는 필터는 없었다. TTS 두 모델 준비 화면의 제한과 범용 후보 탐색·등록 목록은 서로 다른 범위다. 계정·검색·계열 필터와 home별 수집/등록 상태도 표시 범위에 영향을 준다. 이름·경로의 계열 추정은 확정 식별이 아니다. 상위 경로의 일반 TTS 단서가 더 가까운 Whisper 등의 구체적 단서를 덮는 분류를 수리했다. 개인 인벤토리 내용·계정·식별자는 게시하지 않는다.

## 이번 검증

- 새 합성 메타데이터의 직접/API 테스트 18개를 통과했다. 목적 5종, 번호 없는 전체·파일 모드, 동점/페이지/필터, 모호·미지원·부분 후보, TAPIR 단일 파일 및 이미지 분산 구조 보류, 읽기 전용 DB 경계를 확인했다.
- 첫 전체 회귀에서 기존 빈 home 서버 테스트가 읽기 전용 DB 미존재 처리 오류를 발견했다. 빈 조회는 파일 생성 없이 빈 결과로 처리하도록 수리했고 targeted server 4개를 통과했다. 실패 로그는 별도 보존했다. 전체 재회귀는 400개 중 393 PASS / 7 SKIP / 오류 0(56.346초)이다. SKIP은 tracking CPU 의존성 4개·decode 의존성 2개와 Windows 비특권 symlink 1개다. 독립 최종 검토는 동결 뒤 기록한다.
- TypeScript 검사와 Vite 정적 빌드를 통과했다. 실제 Windows 패키지 추천 화면·좁은 폭·에러 회복의 새 관찰은 아직 미기록이다.

새 작업 디렉터리와 새 실행 로그를 사용한다. 같은 프로젝트의 승인된 코드·문서와 공개 고정 의존성만 사용하며 과거 생성 출력·테스트 로그·스크린샷을 이번 성공으로 대체하지 않는다. 새 host 의존성은 격리 venv에만 설치했고, 공식 PyPI에서 고정 wheel 12개 5,712,418 bytes를 새로 수신해 SHA를 검증했다. 공개 패키지 캐시도 별도 기록했다. 모델 다운로드·복사·추론·Drive 수집/쓰기·기존 home 이관은 수행하지 않는다.

## 보존과 한계

0.16.0은 기본 home 이름을 기존 desktop-0.15.0으로 유지한다. 이전의 다른 home 인증을 자동 복구·이관했다는 뜻은 아니다. 새 검증 설치는 명시적 격리 home만 사용한다. 기존 선정 파일의 보존 비교와 새 설치 payload 검증은 실제 단계 뒤 기록한다.

이미지 root 전체 가중치, 정확한 모델 identity/revision/full SHA, runtime·자원 충족, 실행 성공·품질은 추천 메타데이터만으로 확인되지 않는다. 이번 변경은 로컬/외장하드 통합 탐색이나 모델 실행 지원 확대가 아니다. 공개 Release·별도 PC·실계정 새 OAuth·모델 추론은 이번 검증에 포함하지 않는다.
