# 모델 준비 화면 가독성 · Windows 0.16.5

상태: 소스와 합성 미리보기 검증 완료, 새 portable 패키지 및 실제 네이티브 화면 검증 진행 중. 새 GitHub Release나 태그를 뜻하지 않는다.

## 변경

앱 추론 환경과 모델 파일 준비를 각각 흰 카드로 나누고 단계·제목·상태·주요 버튼의 위계를 구분했다. 본문은 진한 중립색, 입력과 선택은 44px 높이를 사용한다. 첫 환경 준비에 인터넷과 수 GB 공간이 필요하다는 안내는 항상 보인다. Python 포함 설명, runtime ID, 복사·해시 관련 기술 설명은 기본 접힌 `자세히 보기`에서 확인한다.

진행 상태, 오류, 원본 폴더, 선택 모델과 preflight 파일 정보는 접지 않는다. 기존 선택자·핸들러·busy/disabled 조건·취소·경로 trim 검사와 native 경로 전달은 유지한다. 화면 개선은 모델 파일 준비나 추론을 수행한 결과가 아니다.

## 이번 검증

- TypeScript/Vite 빌드와 기존 desktop·package integrity·local mode·native guard·view contract 관련 40개 회귀 테스트가 통과했다. 첫 테스트 명령은 PYTHONPATH 미지정으로 import 오류였으며, src 경로를 지정한 최종 실행 40개 통과와 구분한다.
- 실제 컴포넌트와 CSS에 브라우저 메모리의 합성 bridge만 연결한 비공개 미리보기를 사용했다. 실제 backend·인증·파일 접근·모델 실행·다운로드는 연결하지 않았다. 미리보기 HTML과 fixture는 저장소와 패키지에 포함하지 않는다.
- 1266px 컴포넌트 미리보기에서 기본·진행·실패·접근 거부 상태별 표본을, 768px에서는 기본 상태 표본을 확인했다. 768px 표본의 문서 가로 넘침은 없고 입력·선택 높이는 44px였다. 이 폭은 실제 네이티브 앱 shell 폭 검증과 다르다.
- 기본 닫힌 두 details, 상시 보이는 상태·오류·preflight, 취소와 직접 경로 준비의 합성 메서드/모델 ID/경로 전달을 확인했다. 비반환 setup 12개와 기능 JSX 속성 19개의 AST 비교가 동일했다. 이는 실제 native 폴더 선택과 모델 준비 실행 성공 증거가 아니다.

실제 새 네이티브 화면, 모델 파일 준비·취소, 추론·다운로드·OAuth, 스크린리더·모든 폭과 상태는 별도로 구분한다. 기존 인증·자료·모델 원본을 변경하지 않는다. 기존 로컬 모드 및 보안 경계는 [0.16.4 문서](TYPOGRAPHY_LOCAL_0164.md)를 따른다.
