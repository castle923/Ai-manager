# 0.16.2 기능 점검과 수정 범위

이번 변경은 모델 관리 검색창의 돋보기와 입력 글자가 겹치는 CSS 우선순위를 수정한다. 등록 모델의 현재 실행 조건이 차단된 경우 실행 버튼과 실행 요청 함수가 같은 조건을 사용한다. 환경 점검과 모델 준비로 이동하는 경로는 유지하며, 차단을 영구적인 실행 불가 판정으로 취급하지 않는다.

등록 목록은 검색·상태·보관 조건에 연결한다. 새로운 조회가 완료되지 않았거나 실패하면 이전 목록을 숨기고 이전 상세 정보에 대한 변경과 실행을 차단한다. 늦은 응답은 활성 조회와 선택을 확인한 후 반영한다. 조회 오류는 편집·실행 오류와 분리하고 정상 조회에서 해제한다. 등록한 1.7B CustomVoice에서 준비 화면으로 이동하면 동일한 모델을 초기 선택한다. 지원하는 모델 종류나 준비 출처·계정 범위를 확대하지 않는다.

파일 크기는 수집한 메타데이터의 관찰값이다. 미수집은 미수집으로, 관찰된 0은 0 B로 유지한다. 상단 합계에 선택 수집 기록 전체라는 범위를 표시한다. 검색 결과의 크기 합계나 모델 전체 가중치 크기라는 의미가 아니다. 기존 데이터 값을 변경하지 않았다.

## 이번 실행에서 확인한 근거

| 항목 | 결과와 범위 |
| --- | --- |
| 검색 겹침 | 기존 실행 화면과 CSS 우선순위에서 원인 확인. 수리한 합성 화면에서 아이콘과 placeholder 간격을 관찰했다. 좁은 폭·입력·focus 전체 시각 회귀는 미확인이다. |
| 실행 조건 | 새 metadata-only 합성 1.7B 상태에서 runtime 미준비·실행 차단인데 입력 후 버튼이 활성화되는 기존 동작을 재현했다. 수리 코드는 독립 정적 검토와 TypeScript 빌드를 통과했다. 최종 입력 후 실화면 회귀는 자동제어 불안정으로 미확인이다. |
| 준비 선택 | 합성 1.7B에서 이동 후 0.6B가 선택되는 기존 동작을 재현했다. 선택 전달 수리는 독립 정적 검토와 빌드를 통과했다. 수리 후 동일 동작의 실화면 검증은 미확인이다. |
| 조회 오류와 회복 | 합성 조회 장애와 새 검색에서 구목록 잔류, 정상 회복 후 오류 배너 잔류를 새 AX 관찰로 재현했다. 수리 코드의 조회·선택 보호는 독립 정적 검토를 통과했다. 수리 후 UI 장애·회복 검증은 미확인이다. |
| 크기 의미 | 새 합성 데이터에서 0·미수집·혼합·양수와 전체 합계 범위를 독립 검증했다. 실제 사용자 화면의 특정 0 B 오류는 확인하지 않았다. |
| 등록·편집·보관·설정 | 새 격리 home의 실제 로컬 API에서 19 assertions 통과. 등록, 중복·잘못된 입력 차단, 편집 충돌, 태그 검색, 보관·복원, 설정 revision 충돌과 rollback, 서버 재열기 후 보존을 확인했다. 인증은 stub이며 실계정 검증이 아니다. |
| 전체 Python 회귀 | 새 실행에서 406개 중 399 PASS, 7 SKIP, 오류 0. 추적 CPU 의존성 4개, 영상 decode 2개, symlink 권한 1개는 실행하지 못했다. |
| 프런트엔드 | TypeScript 검사와 Vite 빌드 통과. |

지원 자동제어가 최신 창 상태와 다른 메뉴를 대상으로 처리하는 관찰 불안정이 발생하여 반복 입력을 중단했다. 이 제한은 제품 기능 실패나 수리 성공으로 대신 판정하지 않는다. 잘못 이동한 합성 화면에서 준비·다운로드·모델 실행을 요청하지 않았다.

로그인, 실제 Drive 수집, 실모델 파일 검수, 모델 준비·다운로드, TTS/STT/TAPIR/이미지/LLM 추론과 A/B 생성은 이번에 실행하지 않았다. 자동 검수·등록 모델 검증·환경 점검·실제 추론은 각각 다른 근거다. 기존 사용자 앱과 home을 교체하지 않았으며 새 Release나 태그를 게시하지 않는다. 패키지와 설치본의 검증은 소스 검증과 별도로 판정한다.
