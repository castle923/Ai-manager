# M2 조회 대시보드 구현·검증 기록

기록일: 2026-10-16 · 버전: **0.2.0** · 판정: **승인된 M2 조회 대시보드 구현·실제 목록·독립 검증 완료**

## 승인과 입력

사용자가 승인한 범위는 실제 수집 인벤토리의 검색·필터·모델 상세 대시보드 UI 구현, 가능한 범위에서 높은 완성도의 기능·작동·UI, 새 검증과 저장소 반영이다. 작업공간 커스텀과 M3 이후의 다운로드·환경 준비·추론·새 비교·개인용 출시는 이 단계에 포함하지 않는다. [승인 기록](APPROVALS.md)

조회 입력은 동일 Ai-manager 프로젝트에서 수집한 비공개 인벤토리다. M1 기록은 당시 결과로 보존하고 이번 M2에서 현재 코드의 새 자동 검증과 실제 화면 사용 흐름을 확인했다. 계정 A는 이번 검토에서 앱의 새 수집을 1회 수행했고 COMPLETE·436개 파일 관찰·101개 폴더·101개 페이지·오류 0건을 확인했다. 계정 B는 기존 현재 스캔 113개 관찰을 조회했다. B 재수집이나 두 계정 재인증을 이번에 수행했다고 주장하지 않는다.

현재 조회 집계는 549개 계정별 파일 관찰, 77개 부모 폴더 후보 묶음, 292개 가중치 후보, 약 291.4 GiB의 관찰된 파일 크기 합계다. 계정 간 중복 제거를 하지 않았으며 77개 실행 가능 모델·549개 모델·실제 로컬 디스크 사용량이 아니다. COMPLETE는 지정 허용 범위의 페이지 처리를 마쳤다는 뜻이며 두 Drive 전체 목록의 완전성 증명이 아니다.

## 구현

React·TypeScript·Vite 기반의 새 조회 화면과 Python 읽기 전용 조회 API를 작성했다. 최신 계정별 스캔을 기본으로 선택하며 수집 이력 선택, 후보 묶음/파일 보기, 검색, 계정·용도 후보·파일 유형 필터, 이름·크기·수정 시각 정렬, 페이지 조회와 상세 대화상자를 제공한다. 연결·토큰 갱신·수집·연결 해제·작업 취소는 기존 승인된 앱 흐름을 유지한다.

묶음은 계정과 실제 부모 폴더 정체성으로 구분한다. 같은 이름의 서로 다른 폴더가 한 모델로 합쳐지지 않는다. 용도는 파일 경로 기반 추정이며 정식 모델 판정이 아니다. 상세의 config·tokenizer·분할 파일 관찰은 구성 충족 증명이 아니다. 구성·무결성·런타임·실행 상태는 미확인으로 유지하며 Drive 메타데이터의 체크섬을 실제 바이트 검증 결과처럼 표시하지 않는다.

## 이번 검증

| 확인 항목 | 새 검증 결과와 범위 |
|---|---|
| Python 기능·회귀·읽기 전용 API | unittest 30개 통과, 독립 검토에서 동일 테스트 통과 |
| TypeScript·UI 빌드·의존성 | tsc 및 Vite 프로덕션 빌드 통과, npm audit 보고 취약점 0건. 전체 보안 보증은 아님 |
| 새 설치와 배포 구성 | 현재 소스를 분리한 새 환경에서 npm ci --ignore-scripts·빌드 통과, 새 서버의 HTML·JS·CSS·빈 대시보드 API 200 확인, PEP 517 wheel에 정적 자산 3개 포함 확인 |
| 실제 수집 목록 E2E | 실제 목록 검색·계정/용도/유형 필터·정렬·페이지·이력·묶음 및 파일 상세와 새 A 수집 완료 확인 |

| 키보드·대화상자 | Tab 포커스 순환·Escape 닫기와 포커스 복귀·대화상자 중 Ctrl+K 방어·배경 스크롤 잠금 확인 |

빌드 담당과 독립 검토자가 각각 새 실행에서 보고한 결과를 정리했으며 문서 작성자가 모든 테스트를 직접 수행한 의미는 아니다. 검토 중 발견한 의존성 취약점·늦은 응답 경합·동명 폴더 묶음·포커스 처리 등을 이번 코드에서 수정하고 다시 확인했다. GitHub 게시의 고정 커밋 대조는 게시 후 최종 완료 보고에 제공한다.

## 설치·출처·보존

Python 3.10 이상, requests 2.32.5와 기존 Python lock을 사용한다. UI는 React/React DOM 19.2.0, lucide-react 0.468.0, TypeScript 5.9.3, Vite 7.3.7, Prettier 3.6.2를 package-lock으로 고정한다. 이번 확인 환경은 Node 24.21.0 / npm 11.19.0이다. 일반 공개 런타임·라이브러리의 공식 참고는 [Vite 빌드 안내](https://vite.dev/guide/build)와 [React createRoot 문서](https://react.dev/reference/react-dom/client/createRoot)다. 소스 설치는 [README](../README.md)의 UI 선행 빌드를 따른다. 생성된 static·node_modules·Python 환경·wheel·개인 증거는 공개 소스에 포함하지 않는다.

같은 프로젝트의 지정된 수집 메타데이터와 코드·문서 후속 갱신은 명시 승인 범위다. 이번 신규 산출물은 대시보드 코드·테스트·화면 빌드·실행 검증·보고서다. 빌드 증거는 비공개 앱 위치의 `<private_app_home>/m2-build-20261016/verification.json`, 실제 목록·새 스캔·반례·시각 검토 증거는 이번 검토의 별도 비공개 실행 기록에 남긴다. 개인 파일명·계정 주소·Drive ID·실제 절대경로·자격 증명·목록 스크린샷을 공개하지 않는다.

확인 범위는 이번 M2 소스·공개 게시 목록·앱의 지정 인벤토리 입력·새 빌드와 검증 출력이다. 다른 프로젝트 결과물 연결은 사용하지 않았으나 이 문서는 PC 전체 또는 모든 과거 저장 위치의 재사용 부재를 보증하지 않는다. 기존 자료는 보존한다. 실제 Google 계정의 권한 철회·취소·만료 실패를 이번 실계정에서 유발하지 않았으며 실패 반례는 합성 검증 범위다. 모델 파일 바이트 다운로드·해시 대조·추론·실제 GPU 실행·공개 서비스 배포는 검증하지 않았으며 M3 이후 별도 승인 범위다.
