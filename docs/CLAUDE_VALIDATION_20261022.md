# TTS·LLM 후보 metadata의 Claude API 검증

검증일: 2026-10-22. 제품 버전 `0.19.0`의 기존 Claude 분류·추천 경로로 TTS와 LLM 두 목적을 새로 검증했다. 사용자는 현재 후보 범위를 확인하고 각 목적의 새 미리보기·전송 조건을 검토한 뒤 앱에서 직접 최종 동의와 전송을 선택했다. 이전 STT 승인이나 과거 네 목적 계획을 이번 전송 승인으로 재사용하지 않았다. 실무는 GPT-6.1 sol / medium, 부모의 조정과 별도 독립 검토로 진행했다.

## 실제 관측

두 목적 모두 작업 상태 `finished`, 오류 없음, 결과 `stale=false`, usage 기반 비용 표시를 확인했다. 개인 보유 목록과 연결되지 않도록 후보 이름은 비식별화했다.

| 목적 | 비식별 후보 | 반환 분류 | 목적 관련성 추정 |
|---|---|---|---|
| TTS | 후보 A | `tts` | `high` |
| TTS | 후보 B | `tts` | `high` |
| TTS | 후보 C | `unknown` | `unknown` |
| LLM | 후보 A | `llm` | `high` |

`high`는 제공된 metadata에 대한 선택 목적의 관련성 추정(`task_fit`)이며 모델 품질·측정 정확도·확률이 아니다. `unknown`은 그대로 보존했으며 임의로 TTS로 바꾸지 않았다.

| 목적 | 관측 입력 토큰 | 관측 출력 토큰 | usage 기반 기본 요율 계산 (USD) |
|---|---:|---:|---:|
| TTS | 1,409 | 336 | 0.0003089 |
| LLM | 1,063 | 117 | 0.0001648 |
| 합계 | 2,472 | 453 | 0.0004737 |

비용은 이번 응답 usage와 적용 기본 요율로 계산한 값이다. 공급자 청구서·세금·계약별 실제 청구액은 확인하지 않았다. 목적별 앱 예산 USD 0.01은 실제 사용액이나 공급자 청구 hard cap이 아니다.

성공 작업자의 실행 경로 근거로 count 2회·Messages 2회를 확인했다. 이는 독립 네트워크 계측기로 관측한 전체 호출 수가 아니다. 이번 문서 갱신을 위해 추가 API 호출이나 모델 다운로드를 수행하지 않았다.

## 검증 범위와 한계

이번 검증은 현재 지정 범위에서 얻은 metadata를 외부 API에 전달하고, 응답·usage·비용·현재 결과 상태를 확인한 것이다. 개인 인벤토리·원시 요청/응답·후보 대응표·계정 및 파일 식별자는 비공개로 보존하며 이 문서에 포함하지 않는다.

후보 이름·metadata 기반 분류는 실제 모델 identity·revision·전체 가중치 확보·무결성 검증이 아니다. 모델 로딩·추론·출력 품질·런타임 호환성·성능도 이번에 검증하지 않았다. 일부 TTS 후보가 `unknown`인 결과를 포함하므로 모든 후보 분류 성공이나 광범위 추천 정확도로 확대하지 않는다.

추가 이미지 후보는 사용자 선택으로 제외했다. 점 추적 후보는 미확인이며 검증하지 않았다. 과거 네 목적 계획 전체가 완료된 것이 아니다. 이전 합성 회귀와 이번 실제 API 관측은 서로 다른 증거다.

기존 인증·DB·모델·보안 설정은 보존했다. 추가 목적·후보 변경·새 전송은 현재 자료와 새 미리보기·비용/한도를 다시 대조하고 해당 범위의 사용자 승인을 확인한다. 실패·timeout·청구 불명에서는 후속 전송과 자동 재시도를 중단한다.
