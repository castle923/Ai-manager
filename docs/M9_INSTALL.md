# Ai-manager 0.9.0 후보 — 작업 기록·보기 설정·차트

기준일: 2026-10-17 · 새 빌드용 사용 안내 · 실제 Windows 검증 전

## 실행과 기존 자료

ZIP 전체를 새 폴더에 풀고 `AiManager.exe`를 실행합니다. `_internal` 등 동봉 파일과 Python 기반을 함께 보존합니다. 별도 Python 설치는 필요하지 않지만 시스템 WebView2 Runtime은 필요합니다. 모델·개인 인증 자료는 ZIP에 포함하지 않으며 처음 추론 환경 준비에는 인터넷과 수 GB의 공간이 필요합니다. 보안 차단을 우회하거나 전역 설정을 바꾸지 않습니다.

처음 작업실에서는 지정 OAuth client/허용 목록 JSON을 선택하고 계정 A/B의 로그인·동의는 시스템 브라우저에서 사용자가 직접 진행합니다. 추론 환경 준비·환경 점검·지정 모델 원본의 크기/해시 확인 후 새 음성을 생성합니다. 지원 실행은 지정 Qwen3-TTS 두 모델이며 목록에 있는 모든 모델의 실행을 지원하지는 않습니다.

기존 설치와 작업실을 덮어쓰거나 자동 이전하지 않습니다. 별도 작업실을 지정해 사용했다면 같은 실행 옵션을 유지하세요. 기본 작업실의 첫 화면이 열렸다고 기존 자료가 삭제된 것은 아닙니다. 모델 등록·실행·WAV 저장의 기본 흐름은 [사용 가이드](https://github.com/castle923/Ai-manager/blob/main/docs/USER_GUIDE.md)를 참고합니다.

## 통합 작업 기록 보기

1. **통합 작업 기록**을 엽니다. Drive 수집·모델 파일 준비·음성 실행·A/B 비교와 현재 런타임/환경 점검 상태 등을 원본 기록에서 모아 봅니다.
2. **기록 검색**, **기록 종류**, **기록 상태**를 고르고 **조건 적용**을 누릅니다. **조건 초기화**로 필터를 해제합니다.
3. **기록 상세**에서 원본 ID·시각·상태·관련 정보를 확인합니다. 비교의 하위 실행과 실행의 부모 비교를 따로 확인할 수 있습니다. **이 원본 ID의 작업 화면** 또는 **관련 관리 화면 · 현재 상태**는 기록 종류에 맞는 화면으로 이동합니다.
4. **이전 페이지/다음 페이지**로 이동하는 동안 조회 기록은 고정됩니다. 새 작업까지 보려면 **최신 기록 새로 불러오기**를 누릅니다.

저장된 과거 이력과 현재 상태 기록은 구분해서 읽으세요. 과거의 “실행 중”은 지금도 실행 중이라는 보장이 아니며, 과거 성공 조회는 새 실행·새 인증·현재 모델 구성의 검증이 아닙니다. 비교 부모와 두 실행은 별도 기록이므로 단순히 합산해 실행 횟수나 평균을 만들지 않습니다. 일부 원본을 읽지 못하면 안내와 확인 가능한 기록을 표시하며 자동 복구하거나 성공으로 바꾸지 않습니다.

## 보기 설정 바꾸기

**설정**의 **작업실 보기 설정**에서 다음 네 항목을 고르고 **보기 설정 저장**을 누릅니다.

| 항목 | 선택과 적용 |
|---|---|
| 다음 시작의 기본 화면 | 모델 관리 / 통합 작업 기록. 다음 시작부터 적용 |
| 작업 기록 한 페이지 | 10 / 25 / 50개 |
| 기록·차트의 시각 표시 | 이 PC의 현지 시각 / UTC |
| 성능 차트의 메모리 단위 | GiB / MiB |

시간·메모리 표시는 저장 후 기록과 차트에 적용됩니다. 입력·모델·계정 권한·허용 폴더·진행 중 실행 조건은 바꾸지 않습니다. 다른 창의 편집 등으로 충돌하면 오류를 확인하고 **현재 값 다시 불러오기** 후 다시 선택합니다.

**설정과 자료의 위치**는 기본으로 **개인 경로 가림**입니다. 필요한 경우에만 **이 PC의 전체 경로 보기**로 이 PC에서 확인하고 다시 가립니다. 화면 공유·공개 게시에는 전체 경로를 노출하지 마세요. 위치 안내는 읽기 전용이며 파일 이동/삭제나 연결·허용 범위 원본 편집 기능이 아닙니다. “자격 증명 저장됨”은 실제 인증 갱신 성공과 다릅니다.

기존 DB 백업/복원은 인벤토리 DB에만 적용됩니다. 등록 모델 DB·보기 설정·인증·모델·런타임·WAV 전체를 함께 복원하는 기능은 아닙니다.

## A/B 성능 차트 읽기

A/B 비교 화면 또는 통합 기록의 비교 상세에서 **차트 측정 항목**을 고릅니다. 총 처리·모델 로딩·음성 생성 시간은 초, PyTorch 최대 할당 메모리는 선택한 GiB/MiB 단위입니다. 바로 아래 표에서 같은 원천값을 확인할 수 있습니다.

**비교 조건과 원본 출처**를 펼쳐 입력 해시·seed/생성 조건·당시 런타임/코드·장치·콜드 조건과 출력 해시를 확인하세요. 모델 revision/manifest 차이는 비교 대상의 의도한 차이입니다. 공통 조건이나 출처가 확인되지 않으면 동일 조건 차트는 **미확인(N/A)**으로 남고 개별 기록값을 표로 확인합니다. 실패·미수집을 0으로 해석하지 마세요.

총 처리는 로딩·파일 검사·프로세스 부가 시간을 포함합니다. PyTorch 최대 할당량은 GPU 전체 VRAM이나 PC 전체 메모리가 아닙니다. 모델별 한 번의 순차 측정은 평균·일반 성능 순위·음질 승자를 뜻하지 않습니다. 수치의 당시 조건과 기록 시각을 함께 읽으세요.

이 안내는 구현 중인 후보의 사용 계약입니다. 실제 검증·제한·공개 배포 상태는 [M9 보고서](https://github.com/castle923/Ai-manager/blob/main/docs/M9_REPORT.md)를 따르며 현재 실제 완료 증거가 아닙니다.
