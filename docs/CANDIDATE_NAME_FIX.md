# 파일 후보 이름·보류 이유 수정 0.16.1

## 범위와 상태

현재 0.16.1 로컬 수정 후보를 검증 중이다. 이 문서는 모델 실행·품질 검증이나 새 GitHub Release 게시를 뜻하지 않는다. 이전 0.16.0 보고서의 성공 기록을 이번 수정의 성공 근거로 대체하지 않는다.

파일 후보의 폴더명에 `Qwen--` 또는 `Qwen__`가 붙으면 기존 전체 경로 요소 비교에서 고정 프로필 이름을 놓쳤다. 모델을 실행하지 않아 생긴 조건이 아니다. 또한 미정의 프로필, 이름 형태 불일치, 주요 파일 관찰 부족과 분산 구조를 같은 일반 문구만으로 파악하기 어려웠다.

## 이름 후보 인식 정책

- 기존 canonical 별칭 하나가 경로 요소 전체와 일치하는 규칙은 유지한다. `publisher/canonical`도 canonical 요소 전체로 관찰한다.
- 고정 manifest에 기록된 게시자 `Qwen`, `openai`, `meta-llama`, `google`와 그 manifest의 정확한 canonical basename을 붙인 `publisher--canonical`, `publisher__canonical` 전체형만 추가한다. 대소문자는 구별하지 않는다.
- 임의 접두사 제거, `models--` 반복 제거, substring 또는 suffix 삭제는 하지 않는다. 미지 게시자, 뒤에 붙인 변형 이름, 서로 다른 프로필을 포함하는 경로는 이름 후보가 되거나 추천번호를 받지 못한다.
- 알려진 별칭과 비슷한 미허용 게시자 형식이 조상 경로에 있어도 보류한다. 다른 프로필을 닮은 조상과 canonical 하위 폴더의 조합도 추정으로 분리하지 않는다.
- 같은 프로필 이름이 경로에서 반복돼도 이름 후보 목록에는 한 번만 넣는다. 물리적으로 다른 후보 그룹·서로 다른 모델 자산을 이름만으로 합치지 않는다.
- 게시자 형식이 일치한다는 것은 폴더 이름의 단서일 뿐 실제 공식 출처, 모델 identity/revision, 전체 파일·SHA, runtime, 추론 또는 품질을 확인했다는 뜻이 아니다.

이름 후보를 인식해도 목적·모델 root·필수 주요 파일 이름/크기·완료 수집·관찰 shard 누락 및 중복 이름 조건을 모두 적용한다. 이미지 분산 가중치는 안전하게 연결하지 않으므로 순위를 계속 보류한다. 전체 파일 보기에는 모델 추천번호를 붙이지 않는다.

## 모델별 근거 표시

목록과 상세에 관찰 basename을 표시한다. 프로필이 없는 후보는 해당 이름에 대응하는 고정 정의가 확인되지 않았다고 설명한다. 허용하지 않은 게시자/별칭 형식은 별도 사유로 구별한다. 상세에서는 실제 관찰한 작업 관련 경로 이름 단서, 이름 형식과 대응 프로필, 현재 목적에 정의된 프로필 목록, 필수 파일별 이름 미관찰/크기 불일치를 보여준다. 생성 HTML로 해석하지 않고 React 텍스트로 렌더한다.

선택된 프로필이 없다는 이유만으로 모델이 존재하지 않거나 실행 불가능하다고 단정하지 않는다. 같은 계열의 다른 Base, VoiceDesign, LoRA, 기타 변형을 자동 지원 모델로 승격하지 않는다.

## 이번 검증 기록

새 합성 입력과 새 실행으로 후보 관련 24개 테스트를 통과했다. namespace 성공·반례, 원래 canonical 이름, 모호한 중첩 경로, 미지 게시자, 이름 suffix, 필수 파일 누락·부분 수집, 분산 이미지 보류, 실제 localhost GET API와 읽기 전용 DB 경계를 확인했다. 전체 회귀는 406개 중 399 PASS / 7 SKIP / 오류 0(59.146초)이다. SKIP은 기존 선택 의존성/권한에 따른 7개이며 이번 모델 추론을 수행한 결과가 아니다. TypeScript 검사와 Vite build를 통과했다.

새 합성 메타데이터를 담은 별도 source preview WebView에서 파일 후보 탐색, 목적 선택, namespace 추천번호, 서로 다른 미정의 모델의 이름별 보류 이유, 상세의 이름 형식 일치·실제 출처 미검증 문구를 실제 관찰했다. 8열 표와 기존 CSS를 유지했다. 이 관찰은 최종 패키지 검증과 구분한다.

현재 지정 작업실의 수집 메타데이터를 이번 소스로 읽기 전용 대조했다. namespace TTS는 이름과 필수 관찰 조건을 충족했으며 이미지의 분산 구조 및 LLM의 관찰 shard 누락은 별도로 보류됐다. DB SHA-256·identity·크기·mtime·행 수·WAL/SHM 상태가 조회 전후 동일했다. 실제 경로와 개별 관측 수치는 비공개로 보존한다. 모델 bytes와 토큰은 읽지 않았다.

Windows 패키지·격리 설치·실제 설치본 화면 검증과 정확한 소스 게시 결과는 이후 게이트를 통과한 뒤 기록한다. 현재 완료로 판정하지 않는다.

기존 작업실 메타데이터 대조는 별도의 비공개 출처 기록으로 보존하며 개인 계정·Drive ID·원본 경로·인벤토리 수치는 게시하지 않는다. 기존 앱은 그대로 유지한다. 새 모델 다운로드·복사·추론·로그인·Drive 수집/쓰기·기존 DB 수정·새 Release 게시를 수행하지 않는다.
